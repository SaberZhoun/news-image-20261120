Sum up the world's news of Friday 20 November 2026 in one image: a dense newspaper front page with 33 stories from 20 November only, across 6 regions — Cyclone Akvan coming ashore in Odisha (300,000+ evacuated), 100+ missiles hitting Kyiv, Asia's markets plunging on the AI sell-off, COP31 deadlocked on its final day in Antalya, and the UK-EU reset deal sealed in Brussels — plus a world map, 20 briefs, and a DATE CHECK box that deliberately excludes 19 November stories (the Shenzhen summit, Anthropic's IPO debut, the Myanmar ruling, the GTA VI launch, Voyager 1).

The program is `main.py` (Python 3.13, standard library only). It writes the 1024x1024 PNG to `/output/entry.png`, deterministically, with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
